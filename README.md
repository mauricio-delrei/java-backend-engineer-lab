\# Java Backend Engineer Lab



A practical engineering laboratory for developing Senior Java Backend and Event Streaming skills.



\## Objectives



This repository contains hands-on exercises covering:



\- Modern Java

\- JVM fundamentals

\- Concurrency

\- Spring Boot

\- REST APIs

\- Databases

\- Redis

\- Apache Kafka

\- Event-driven architecture

\- Testing and TDD

\- Docker

\- CI/CD

\- Observability

\- Security

\- Kubernetes

\- System design



\## Technology Stack



\- Java 21

\- Spring Boot

\- Maven

\- PostgreSQL

\- Redis

\- Apache Kafka

\- Docker

\- Kubernetes

\- Git

\- GitHub



\## Learning Method



Each module follows the same engineering workflow:



1\. Learn

2\. Code

3\. Test

4\. Break and debug

5\. Document

6\. Explain

7\. Commit

8\. Push to GitHub
